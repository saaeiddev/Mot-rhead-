# Asset provenance

- `public/assets/headphones.webp`: original AI-generated product render created for this project. Built-in image generation; a matte black over-ear concept device with stitched leather cushions, metal yokes and an abstract crown, photographed on off-white. Prompt: premium photorealistic three-quarter product view, full headphones, grayscale, no lettering, detailed studio reflections, isolated background and grounded shadow. This is a rendered image with a lightweight CSS entrance/hover tilt, not an interactive WebGL mesh or a real model of a connected product.
- `public/assets/culture.webp`: original AI-generated monochrome street-culture collage created for this project. Prompt: four equal visual zones: graffiti skatepark and skateboard; vintage boombox; palms on a beach; breakdancer under an urban overpass. Gritty 35mm editorial photography, grayscale, no text. CSS background positioning selects each zone without additional image requests.
- `public/assets/demo-beat.wav`: original, deterministic synthetic composition, 120 BPM, 16 seconds, no samples or commercial recordings. Reproduce with `python3 scripts/generate_demo.py`.
- `public/icons`: original geometric crown artwork drawn for MOT-RHEAD.
- Lucide icons: ISC license via `lucide-react`.
- Inter and Barlow Condensed: SIL Open Font License, distributed locally via Fontsource. Font licenses are retained in their npm packages.

No Skullcandy logos, proprietary artwork, firmware protocols or commercial audio are bundled. The reference image supplied by the user guided the art direction; the application assets were generated separately.
